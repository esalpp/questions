## .NET Knowledge Quiz

`dotnet-quiz.html` is a self-contained, 35-question multiple-choice quiz covering C#, LINQ, async/await, the runtime, ASP.NET Core and EF Core.

**How to use:** download or clone the repo and double-click `dotnet-quiz.html` to open it in any browser. No install or internet connection is needed.

- Answer every question. The **Reveal answers** button unlocks once all are answered. If you want to stop early, use "Reveal anyway".
- After revealing, you'll see your score, a per-topic breakdown, the correct answer for each question and an explanation.
- Your answers are saved in the browser, so refreshing won't lose progress.
- **Retake quiz** clears your answers and shuffles the questions and options.

To add or edit questions, change the `QUESTIONS` array near the top of the `<script>` block.
